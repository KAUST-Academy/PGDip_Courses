# Introduction to Python — Reading List & Resources

A curated set of **free** reading and practice material to accompany the lecture
slides and lab notebooks. Every item below is free to access online; many are
also **bundled as files** in the `Reading_List/` folder for offline use.

> **Licensing:** the bundled books are openly licensed (Creative Commons,
> non-commercial). They're fine for course study — please don't republish them.

## 🚀 Start here (great companions for the whole course)

- **[Automate the Boring Stuff with Python](https://automatetheboringstuff.com/)** — Al Sweigart.
  Free online. Gentle, practical, project-driven — the best all-round companion
  for beginners. *(Days 1–4)* **← recommended starting point**
- **[Think Python](https://allendowney.github.io/ThinkPython/)** — Allen Downey.
  The book is a set of Jupyter notebooks, so it pairs naturally with our labs.
  (2nd-ed PDF is in the folder; the 3rd ed is at this link.) *(Days 1–6)*
- **[Python for Everybody](https://www.py4e.com/book)** — Charles Severance.
  Free, with video lectures and exercises. Strong on data handling. *(Days 1–4, 7)*

## 📖 Official & reference

- **[The Python Tutorial (official docs)](https://docs.python.org/3/tutorial/)** — the authoritative language reference. *(Days 1–6)*
- **[Python Standard Library docs](https://docs.python.org/3/library/)** — reference for modules and built-ins. *(Day 2+)*
- **[Real Python](https://realpython.com/)** — high-quality free tutorials; a great "second explanation" for any tricky topic. *(All days)*
